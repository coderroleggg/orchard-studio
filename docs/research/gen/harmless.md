# Harmless (FL: Harmless)

FL's Harmless is Image-Line's additive synthesizer with subtractive-style
controls. Each voice and unison voice is a bank of up to 528 sine
oscillators: 4 special slots (resonance self-oscillation, sub harmonics 1, 3
and 4) and 524 harmonics. Their levels are shaped in the frequency domain by:

- a timbre colour (11 built-in colours or a custom colour) and the 6-band timbre EQ
- a 12-periodic harmonic mask
- a filter curve (17 types), a resonance curve (8 types + noise) and a phaser curve (10 types)
- a harmonizer and a pluck

These are driven by a filter envelope, an LFO (14 shapes / sources) and a volume envelope, with unison (9 voices, 3 types),
portamento / legato / mono, a stereo tremolo and a global effects chain (chorus, delay,
reverb, compression = a hosted Maximus). Category Synth classic,
`notes: 'events'` (FL's Gen_Render plugin with its own voices), DefPoly 16.

Sources:

- FL 2026's plugin binary (`Plugins/Fruity/Generators/Harmless/Harmless_x64.dylib`, arm64 slice, FPC, class `TTestPlug`, no symbols; RTTI field table of the editor form)
- FL's IPP-compatible vector library (`Shared/dsp_ippv2_x64.dylib`)

Tooling lives in `.flref/harmless/` (git-ignored):

## State, parameters, presets (`src/model/gen/plugins/harmless/`)

- 100 parameters with FL's ranges, reset values and exact value texts (`params.ts`; 155,212 texts checked against FL's
  GetName, 0 mismatches). FL's number formatting is `flFixed`.
- Extra state (`state.ts`): filter / resonance / phaser / compression type, timbre colour, threaded, quality (FL's combo
  values = selectable item indices), `kbShown` (view). The custom timbre colour (524 amplitudes + 524 phases in cycles)
  lives in the sample pool (`customSample`, mono float frames).
- Presets (`presets.ts`, generated by `.flref/harmless/model/gen_presets.py`): the 430 factory presets as FL loaded and
  re-saved them through the test host, as differences to the plugin database state, deflated + base64. A new instance
  plays the database state.
- 118 presets use a custom colour. That is FL's waveform analysis (content), so it is not shipped: these presets carry
  `customMissing` until the user imports the colour.
  - The plugin menu's "Import FL content..." reads the user's own FL presets (folder or files). It finds the preset whose
    parameters and extras all equal the state's, and stores its colour in the pool (`flimport.ts`, `import.ts`).
  - "Analyze single-cycle waveform..." (FL 0x74380 / 0x744e0) builds a colour from an audio file taken as one period.
    FL resamples it to 2048 samples and takes a real FFT. From bins 1..524 it keeps |X| scaled to a maximum of 1, and the
    phase arg(X) / 2 pi + 0.25. The port takes the DFT at the file's own length instead of FL's resampler.
  - "Reset custom timbre color" (0x74720) drops the colour; a Custom selection falls back to Saw.

## Voice engine (exact port, `src/engine/gen/plugins/harmless/`)

Notes arrive as events at their sample. At the same sample a note off goes before another note's note on, as in FL
(so touching notes do not overlap for legato / porta), whatever order the channel's voice slots send them in.

Control period: 88 / 44 / 8 samples (quality 0 / 1 / 2) times FL's host factor **44100 / sr**, rounded to a multiple
of 4. FL scales by the inverse of the rate: 80 samples at 48 kHz.

Per control block (`core.ts` `control`):

1. **Glide**, filter envelope (attack / decay with FL's slope shaping records), cutoff smoothing.
2. **Pitch:** vibrato (sin of a phase shared by all voices), the LFO, unison detune (`UNISON_TABLE`, FL's float
   constants).
3. On a pitch change:
   - the harmonic count below FL's 17 kHz limit
   - ratios x f / sr (+ grittiness sines)
   - the Hz / log2 Hz tables
4. **Levels:**
   - harmonic mask (or the pluck mask)
   - harmonizer at its position
   - filter: clamped curve lookup at quality 0, linear above
   - resonance, or noise: random uniform gains thresholded to 0 or sqrt(k + 1)
   - phaser: periodic curve; "Freq" moves the frequencies
   - pluck: per-harmonic exponential decay, starting after the attack and at least 2 ms in (FL takes the *smaller* of the
     two step counts)
   - low harmonics protection, sub levels, the top fade of slots 464..527
5. **Self-oscillation slot frequency and targets** to the sine bank (activation at -96 dB, 2^-24 above quality 0).
6. **First block:** phases from the timbre phases, phase randomness and the unison phase.

The sine bank renders recursive float32 oscillators in groups of 8 lanes:

- FL's lane order and summation order
- per-sample amplitude glides
- re-sync from double phases every round(f x 8192) samples (FL's ippsSin_32f)
- compaction every 512 samples

The volume envelope runs as two ramps; release time x FPV_GetRelTime (2 - 2 x release velocity) when "release velocity
to release" is on. Then the stereo out with FL's pan law (cosf / sinf) and ramp kernel, and the tremolo:

- ippsTone_Direct_32fc as FL's IPP library computes it (`tone.ts`)
- the |1.25 cos|, |1.25 sin| gains
- a 0.1 s fade-in for new voices

A voice whose envelope ends below -80 dB fades out over 30 ms (stage 9) and is removed by the host kill pass.

FL quirks the port keeps:

- **Threaded rendering.** With "threaded" on and several voices, FL renders voices in parallel threads.
  - A voice's fade-out decision reaches the other voices of its note only from the next block. The port defers kills
    in that case.
  - FL mixes voices that finish late after the main mix pass. Their summation order varies run to run, about -100..-140
    dB.
- **Random generator.** FL seeds it from the clock, so FL's own renders differ run to run for presets with negative
  phase randomness or random LFOs. The port seeds 0x12bd6aa, FL's seed before the clock reseed.
  - The test harness pins FL with a CACurrentMediaTime shim (`tools/libcamt.dylib`: 1000 s -> MT seed 1e9) and seeds
    the port alike.
- **Timbre colour parity tests use Trunc**, so the sub slot at harmonic 1.5 counts as odd. The custom colour index uses
  Round.
- **Noise resonance.** Values below k become 0, the rest become sqrt(k + 1) (ippsThreshold_GTVal with level 0).
- **Cutoff law.** Cutoff = f32(lo + v x 2^-13 x range), computed in double.
- **Velocity.** The plugin reads FPV_GetVelocity: FL's velocity law back again, 0.78125 ln(10 InitLevels.Vol + 1) /
  ln 11 in float. Velocity 120 gives 0.93749.., not 120 / 128.
- **Note colours.** Colours 13 / 14 ("inverted" legato / porta) set the note's colour to 0 when the mode is off, both
  for the slot and for the voices made after the check.

## Global effects (`fx.ts`)

Chorus -> delay -> reverb -> compression, in place on the voices' mix (Gen_Render 0x733fc..0x7364c). There are no
dry/wet ramps; the only ramp is the delay feedback (<= 0.001 per sample). The reverb's wet add is fused (vDSP_vsma).

- **Updaters.** ProcessParam runs the updaters at once (90/91 chorus, 92..95 delay, 96/97 reverb, 98 compression
  amount = SGv2 parameter 5). A tempo change re-runs the delay updater.
- **Compression.** The compType combo loads SGv2 (Maximus) with Harmless's `Data/Compression/<type>.fst`. Those states
  are embedded as constants; type 4 needs 2x oversampling.
- **Units.**
  - Chorus: the same TStereoFlanger as Harmor, with type records (Harmor's `fx-chorus.ts`).
  - Delay: an older TDelay_32FS class. Types: Classic; Ping-pong (+1 ms right, cross feedback); Stereoized (-20 ms left,
    cross feedback). Time = P95 / 48 beat.
  - Reverb: Harmor's TFruityReverb core with fixed type records; wet = LogVol(P97) / 2.
- **Tail.** A counter (PL+0x7c8) is reloaded from rint(0.004 sr), plus the block and chorus delay length with chorus,
  while voices exist. The chorus runs and the delay takes input only while it is positive. Delay output, reverb and
  compression run every call.

FL calls Gen_Render every block. So the instance stays active (`tail` = Infinity), and the free-running phases keep
moving through silences: phaser motion, global LFO, vibrato, tremolo, the phase-randomness counter, the chorus LFOs.

Fidelity:

- **Parameter sweeps** on the new-instance state: 97 of 97 bit-exact. They cover:
  - 9 chorus types x 4 mixes
  - 3 delay types x 5 settings
  - 6 reverb types x 4 wets
  - 4 compression types x 4 levels
  - 6 all-on combinations
- **Also bit-exact:** automation of every effect parameter (including switching units off and on), tempos 60.5..174
  BPM, 22.05..96 kHz, host blocks of 256 / 333 / 1000, and the four compression states against FL's SGv2 itself.
- **All 431 presets with effects,** key 60, best of 2 FL runs: 234 bit-exact. The rest have a median of -134 dB
  (quartiles -142 / -123). They are within FL's own run-to-run variation, for example Lucky Emerson 1 at -79 dB between
  FL runs.

## Editor (`src/ui/plugins/gen/harmless/`)

- Every control sits at FL's form position. `layout.ts` is generated from the form resource and holds 110 controls with
  their hints and combo items.
- The captions are FL's painted labels (`labels.ts`). They come from the painter's label calls: anchor control, mode,
  offsets, alpha, with the label helper's box rules decoded.
- The drawing is original (`paint.ts`, `widgets.tsx`): silver knobs with coloured rings, thin sliders, LED boxes, dark
  combos.
- The keyboard button hides FL's keyboard strip (form 569 -> 502 high). The keyboard plays the channel and lights the
  playing keys.
- The timbre combo's right-click menu is FL's HarmColMenu (analyse / reset). The plugin menu has "Import FL content...".
